# 진심으로 행복을 기원합니다 🌸

## GitHub Pages 올리는 방법
1. GitHub에서 새 저장소를 만들거나 기존 저장소를 엽니다.
2. 이 ZIP의 압축을 풀고 `index.html`, `style.css`, `app.js`, `manifest.json`, `service-worker.js`, `icons` 폴더를 저장소 최상위에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치 / `/(root)`를 선택한 뒤 Save를 누릅니다.
5. 잠시 후 표시되는 GitHub Pages 주소로 접속합니다.

## 주요 기능
- 명단과 가족기원문을 별도 화면에서 날짜별 체크
- 2026년부터 연도·월 선택
- 이름/기원문 추가·수정·삭제
- 체크 즉시 브라우저에 자동 저장
- 백업 내보내기(상단 ↓), 백업 복원(상단 ↥)
- PWA 설치 및 오프라인 캐시

## 꼭 알아둘 점
- 현재 버전은 브라우저의 LocalStorage에 저장합니다. 같은 기기·같은 브라우저에서 유지됩니다.
- PC와 휴대폰 사이 자동 동기화는 되지 않습니다. 한 기기에서 백업 파일을 내려받은 뒤 다른 기기에서 ↥ 버튼으로 복원하세요.
- 브라우저 데이터 삭제 또는 기기 변경 전에 백업 파일을 꼭 보관하세요.
- 온라인 폰트는 인터넷 연결 시 적용되며, 오프라인에서는 기기 기본 글꼴로 표시될 수 있습니다.
- 기원문 중 건강 관련 문장은 사용자가 제공한 표현을 바탕으로 기록용으로 구성했습니다. 앱은 의료 진단이나 치료를 제공하지 않습니다.
