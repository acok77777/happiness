# 진심으로 행복을 기원합니다

GitHub Pages용 가족 기원문 앱입니다.

## 업로드할 파일
- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- 아이콘/icon-192.png
- 아이콘/icon-512.png

아이콘 PNG는 사용자가 준비한 기존 파일을 `아이콘` 폴더에 넣어 주세요.

## 배포
GitHub 저장소 `happiness`의 최상위에 위 파일을 올리고 Pages를 활성화합니다.
앱의 체크 데이터는 현재 사용 중인 브라우저의 localStorage에 저장됩니다.
기기 변경이나 브라우저 데이터 삭제 전에 앱 안의 `백업파일 저장`을 이용해 주세요.

## 공유 미리보기
Open Graph 이미지는 기존 `아이콘/icon-512.png`를 사용하도록 설정되어 있습니다.
정사각형 아이콘도 공유될 수 있지만, 카카오톡 등 서비스의 캐시 갱신 및 이미지 크기 정책에 따라 반영까지 시간이 걸릴 수 있습니다.
